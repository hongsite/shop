## 框架定位

**不是一套商城，而是一套通用后台管理系统底座。**

- 商城功能仅为**演示模块**，用于验证框架能力。
- 核心是可复用的**权限、用户、菜单、日志、通用增删改查**底座。
- 换业务 = 换几个数据表 + 几个标签模板页面，**无需改框架**。
- 一次学会，全场景复用。

---

核心特性

极速
服务端只输出API接口**原生渲染**，页面直出，无打包、无构建、无前端编译。
单页响应毫秒级，轻量无冗余依赖。
支持PHP 7.2+mysql5.7.44，老服务器照样丝滑运行。

###极简
- **零配置启动**，一个 `index.html` 方法即可跑起来。
- **无复杂注解、无繁琐 XML**，上手即写。
- 极简目录结构，新人 10 分钟看懂全项目。

###可扩展
- 通用底座 + 模块化开发。
- 新增业务模块仅需：建表 → 写标签模板 → 挂菜单。
- 商城 / ERP / CRM / 进销存 / OA / 会员系统一套框架全搞定。

###标签模板原生渲染
- 页面采用**自定义标签模板**编写，服务端输出api接口**客户端原生渲染**输出 HTML。
- 无需前后端分离、无需 Node 环境、无需打包构建。
- 写标签 = 写页面，开发效率极高。

## 标签模板原生渲染

框架采用**标签模板原生渲染**，页面即模板，模板即页面：

```html
<!--moban-begin-->
<!--foreach($list){
<li>
<div class="title">{$title}</div>
<div class="order-amount">¥ {$payprice|formatp=###}</div>
<div class="">{$stat|dics=###,statlist,'write'}</div>
</li>
}-->

<!--foreach($vo){
<li>
<p>{$title}</p>
<p>{$value|formatp=###,0}</p>
<p>{$sex|dics=###,sexlist,'select','sex'}</p>
</li>
}-->
<!--moban-end-->
```

模板以<!--foreach($list){开始}-->结束,所有标签只允许有一个以<!--moban-begin-->开始<!--moban-end-->结束

### 原生渲染流程
```text
浏览器请求 → 服务端输出api接口
→客户端解析标签模板
→ 原生渲染完整HTML
→ 浏览器解析输出
```

### 标签模板优势
| 对比项 | 本框架 | 前后端分离 | 传统 JSP |
| --- | --- | --- | --- |
| 构建打包 |  无  |
| 首屏速度 |  极快 | 需接口+渲染 | 较快 |
| 学习成本 | 极低 |
| 扩展新页面 | 一个模板 | 前端+后端 | 一个页面 |

## 目录结构

```text
HSTADMIN/
├── static/                 # 原生 JS、CSS、图片等静态资源
├── api/                    # 接口文件（PHP）
├── pro/                    # 【示例】功能模块：商品管理
│   ├── index.html          # 页面
│   ├── index.js            # 功能 JS
│   └── index.css           # 功能 CSS
├── orders/                 # 【示例】功能模块：订单管理
│   ├── index.html
│   ├── index.js
│   └── index.css
├── ordersagent/            # 【示例】功能模块：分销订单
│   ├── index.html
│   ├── index.js
│   └── index.css

#└── docs/                   # 文档
```

> 除 `static` / `api` 外，**每个功能一个目录**，内部统一包含 `index.html`、`index.js`、`index.css` 三个文件；新增功能只需新建一个功能目录。

## 快速开始

### 1. 环境要求
- PHP 7.2+（Apache / Nginx + PHP-FPM）
- MySQL 5.7.44
- （可选）微信小程序账号，用于分销商城演示

### 2. 初始化数据库
```bash
mysql -u root -p < sql/init.sql
```

### 3. 配置
编辑根目录 `config.php`：

```php
// 数据库
'DB_HOST' => '127.0.0.1',//数据库链接地址
'DB_NAME' => 'shopb',        // 数据库名
'DB_USER' => 'root',      // 用户名
'DB_PWD'  => 'root',//用户密码
'DB_PORT' => 3306,//数据库端口
```

### 4. 部署
将项目放入 Web 根目录（如 `/`），即可直接访问：

浏览器访问 `http://localhost/ `，默认账号 `admin / hst666888`，即可看到运行中的后台管理界面与分销商城演示。

## 演示模块：微信分销商城

> 商城仅作为**框架能力演示**，展示标签模板、原生渲染、通用增删改查的真实用法。

### 已内置功能
- 商品管理（增删改查 + 图片 + 规格）
- 订单管理（列表、详情、状态流转）
- 分销管理（三级分销关系、佣金比例配置）
- 分销员提现（审核、打款）
- 会员 / 用户管理

### 商城模块技术说明
| 页面 | 使用的框架能力 |
| --- | --- |
| 商品列表 / 编辑 | 标签模板 `<table>` + `<form>` 通用渲染 |
| 订单列表 | 联表查询 + 条件过滤 + 分页 |
| 分销关系 | 树形标签渲染 |

## 扩展为其它系统

框架的通用底座让扩展变得极其简单，**三步即可新增一个业务模块**：

```text
第一步  建数据表（sql/ 下）
第二步  新建功能目录，编写 index.html / index.js / index.css
第三步  注册菜单pub/header.htm
```

### 可快速落地场景
-**进销存**：货品、入库、出库、盘点
-**CRM**：客户、跟进、合同、回款
-*OA**：审批、公告、考勤、日程
-**电商后台**：商品、订单、售后、财务
-**会员系统**：会员、积分、储值、权益
